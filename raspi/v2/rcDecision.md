## 개요
- `rcDecision.py`에 `rcDecision` 클래스를 추가하여 재배사의 환경 센서값과 릴레이 상태를 기반으로 제어 결정을 수행하고, `jayeondeule.py`의 `main_loop`에서 해당 결과를 저장하도록 확장한다.

## 주요 요구사항 정리
- 입력 데이터: 실내/실외 온도, 실내 습도, 실내 조도, 수온, 실내 CO₂, 기타 센서값과 모든 릴레이 현재 상태.
- 온도 제어:
  - 실내온도 ≤ 26 ℃: 수온히터(`relay_1st_flag`) On, 공기순환밸브(`relay_10st_flag`) On, 10초 지연 후 흡입팬(`relay_5st_flag`)·배출팬(`relay_6st_flag`) On, 배수밸브(`relay_3st_flag`) On, 수온 ≥ 36 ℃ 시 포그(`relay_2st_flag`) On, 수온 ≤ 30 ℃ 시 포그 Off.
  - 실내온도 ≥ 29 ℃: 수온히터 Off, 공기순환밸브 On 유지, 흡입팬·배출팬 Off, 배수밸브 On, 포그 Off.
- 수온 안전: 수온 ≥ 45 ℃ 이면 수온히터 Off.
- CO₂ 제어:
  - 실내 CO₂ ≥ 1500 ppm: 공기배출밸브(`relay_14st_flag`) On, 10초 지연 후 배출환풍모터(`relay_6st_flag`) On.
  - 실내 CO₂ ≤ 700 ppm: 배출환풍모터 Off, 10초 지연 후 공기배출밸브 Off.
- 기존 칠러 보호 로직 및 다른 제어 흐름은 유지.

## 구현 계획
- `rcDecision.py`
  - `rcDecision` 클래스 정의, 센서값과 릴레이 상태 객체를 입력받아 제어 결과를 반환하는 메서드 작성.
  - 센서 입력 키(실내/실외 온도, 실내 습도, 수온, CO₂ 등)는 클래스 상수로 선언하여 사용처 전반에 일관성 유지.
  - 온도/수온/CO₂ 조건에 따른 릴레이 설정 함수 분리 및 우선순위 충돌 처리.
  - 지연 동작(10초 후 On/Off)을 위한 타임스탬프 관리 로직 추가.
- `jayeondeule.py`
  - `rcDecision` 인스턴스 생성 및 `main_loop` 내 `# 이곳에 삽입` 위치에서 센서값·릴레이 상태를 전달하고 결과 릴레이 상태를 저장하도록 연동.
  - 기존 DB 저장, 칠러 보호 로직, 수동 제어 분기 등은 변경하지 않고 호출 시점만 추가.

## 테스트 및 검증
- 조건별 센서 시나리오 모의 데이터를 사용하여 각 릴레이가 요구사항대로 변경되는지 검증.
- 온도/수온/CO₂ 경계값(26/29/30/36/45 ℃, 700/1500 ppm)에서의 동작 확인.
- 10초 지연 로직 동작 여부, 반복 호출 시 상태 지속성 확인.
