    Retrieval: MCP, Learn Method: RAG  
  * 재배사: 버섯을 생육하는 공간으로 샌드위치 판넬로 건축한 구조물
  * 센서: 온도, 습도, Co2, 수온, 조도, 
  * 릴레이: 관수밸브, 분사펌프, 배수밸브, 열풍기, 열풍밸브, 흡기팬, 배기팬, 흡기댐퍼, 배기댐퍼, 순환댐퍼

[용어정의]
  * 공기흐름: 바닥 2열 덕트로 흡입 -> 환풍기 -> 열냉가습기 -> 환풍기 -> 상단 1열 덕트로 배기
  * 열냉가습기: 스테인리스 재질의 직사각형 본체에 공기흡입구, 공기배기구, 지하수 저장탱크, 지하수를 데우는 물가열기, 
                그리고 탱크의 물을 강하게 분사하는 분사펌프가 설치되어, 분사펌프가 탱크물을 미세한 물안개 형태로 뿜어내고, 
                공기가 그 물안개를 통과하면서 습기가 더해지고, 이렇게 습기가 포함된 공기가 배기구를 통해 밖으로 배기 시키는 장치
  * 물가열기: 열냉가습기 내부 지하수 물탱크의 물을 데우는 가열장치 
  * 분사펌프: 열냉가습기 내부의 지하수 탱크물을 물안개처럼 강하게 분사하는 장치
  * 배수밸브: 열냉가습기 내부의 지하수 물을 장치 외부로 배출시키는 밸브장치
  * 흡기팬: 흡기댐프와 함께 재배사 외부의 공기를 내부로 유입 
  * 배기팬: 배기댐프와 함께 재배사 내부의 공기를 외부로 배기
  * 조명토글: 재배사 내부의 조명을 끄고 켜는 스위치
  * 관수밸브: 재배사 내부의 버섯을 키우는 배지에 물을 공급(상단에서 하단으로 물을 뿌리는 스프링 쿨러)
  * 열풍기: 강하게 가열된 공기를 뿜어내는 장치
  * 순환댐퍼: 공기의 흐름이 내부로만 순환되도록 조절
  * 흡기댐퍼: 재배사 외부의 공기를 재배사 내부로 흐르도록 조절
  * 배기댐퍼: 재배사 내부의 공기를 재배사 외부로 흐르도록 조절
  * 열풍댐퍼: 열풍기로 가열된 공기를 재배사의 공기가 흐르는 덕트에 공기 유입을 조정하는 밸브장치 
  * 공기순환정지: 내부공기 흐름을 정지
  * 공기내부순환: 내부공기를 흡입하여 내부로 배기를 통해서 내부의 공기상태(온도, 습도, co2 )를 유지 
  * 공기외부순환: 내부공기를 흡입하여 외부로 배기하고 외부공기를 흡입하여 내부로 배기를 통해서 내부공기를 외부공기(온도, 습도, co2 )로 대체
  * 공기흡입순환: 외부공기를 내부로의 배기를 통해 CO2 하락
  * 공기배기순환: 내부공기를 외부로의 배개를 통해 CO2 하락
  * 라지에이터: 열냉가습기 내부의 공기를 라지에이터를 통과시켜 온도를 조절하는 장치

    ** 사용자 인터페이스: Streamlit, FastAPI

[데이터 흐름]
  --> 라즈베리파이: 센서 측정값 측정(3초간격) -> Postgresql DB ->
   -> 중앙서버: Postgresql DB -> 학습(RAG) 데이터생성 -> Vector DB ->
   -> 중앙서버: Vector DB -> 사용자 대화용 소스데이터로 활용,

   -> 라즈베리파이: Postgresql DB -> 릴레이 제어 -->
