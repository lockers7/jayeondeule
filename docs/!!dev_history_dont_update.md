{

- LLM처리 모든 기능은 LLM이 제어하고 대화를위한 데이터를 키워드 필터/검색등을통한 강제데이터 관리는 피하라.

- 함수 추가, 변경, 삭제시 함수포함한 파일의 최 상단에 기존 처리방식의 주석을 보완하고, 함수명 위에도 기존 처리방식의 함수기능 주석을 보완하라.
