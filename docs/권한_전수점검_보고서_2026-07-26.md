## 2. 계층별 권한 구조 (현황)

### 2-1. 프론트 라우트 (App.jsx) — ✅ 역할 분기 정상
- 비로그인 → `GuestRoutes`
- **ADMIN** → `AdminRoutes` (프롬프트관리·룰후보·Agent이력·LLM제어관리 등)
- **FARM_ADMIN** → `FarmAdminRoutes`
- **SYS_MONITOR / FARM_MONITOR** → `MonitorRoutes`
- ⚠️ 단, **모든 번들이 `<Route path="*" element={<CommonRoutes/>}/>`**로 CommonRoutes를 폴백 포함 → CommonRoutes의 `/ai-chat`·**`/stock-trading`**·`/mypage`는 **전 역할이 URL로 접근 가능**(F3).

### 2-2. 프론트 메뉴 (Header.jsx) — ✅ 정상
- `auth.userInfo.authLvel === "ADMIN"` 일 때만 `AdminNavLink`(프롬프트관리·룰후보·Agent이력·LLM제어관리) 표시.
- **주식자동매매 버튼**: 본 점검에서 동일 조건(`isAdmin`)으로 게이팅 완료(F2).

### 2-3. 백엔드 Spring API — ✅ 역할검사 있음
- FarmController·SettingController·RelayController·SensorController 등에서 `userInfo.getAuthLvel().equals(AuthLvel.ADMIN) || ...`로 **서버측 역할검사 수행**. JWT(UserClaimDTO: userId·authLvel·farmId) 기반.

### 2-4. AI FastAPI (8002) — ⚠️ 앱 레벨 인증 없음
- 전 엔드포인트가 `Depends(verify_api_key)`(54개)지만 **`AGRI_API_KEY`가 빈값 → 즉시 통과(무인증)**.
- `API_HOST=0.0.0.0` 전체 인터페이스 바인드. **사용자 역할(authLvel) 전달·검사 없음** — 관리 엔드포인트(`/api/v1/admin/control-prompts`, `models`, `trading/*`, `query`(db_read_query 포함) 등)가 네트워크에서 닿으면 누구나 호출 가능.
- 완화 요인: 프론트는 nginx(443)를 통해 접근하고 UI에서 역할 게이팅. 실위험은 **8002 포트의 외부 노출 여부**에 달림(방화벽 점검 필요).

## 3. 이번 세션 수정 완료 (F1·F2)

### F1 — 대화기록 사용자 격리
- **원인**: `ai_conversation` 테이블은 `session_id`만으로 구분(user_id 컬럼 없음). 프론트가 ADMIN 세션을 **브라우저 localStorage UUID**로 잡고, 농장관리자 `farmId`가 0/null이면 `farm_{id}` 분기(falsy)를 건너뛰어 **시스템관리자와 UUID 공유** → 이전 사용자 대화 표시.
- **수정**(`web/frontend/src/pages/ai/AiChatPage.jsx`): 세션을 **항상 존재하는 로그인ID 기반 `user_{userId}`로 격리**. 세션(사용자) 전환 시 이전 대화 잔여 제거 + 재조회. 백엔드·DB 변경 없음.
- **주의**: 하드 새로고침 후 적용. 과거 대화는 옛 session_id에 있어 사용자별 새로 시작.

### F2 — 주식자동매매 버튼 ADMIN 전용
- **수정**(AiChatPage.jsx): `{isAdmin && (<Button …주식자동매매/>)}` — `authLvel==='ADMIN'`(관리메뉴와 동일 권한)일 때만 표시. 그 외 숨김.

## 4. 권고(미변경 — 지시대로 정확 확인 후 진행)

- **F3**: `/stock-trading`을 **ADMIN 전용 라우트로 가드**(AdminRoutes로 이동 또는 라우트 레벨 role check). 버튼 숨김만으론 URL·창재사용 우회 가능. → 진행 지시 주시면 라우트 가드 추가.
- **F4**: ①`AGRI_API_KEY` 설정 + FastAPI에 사용자 역할 전달·검사 도입, 또는 ②8002를 **내부 바인드(127.0.0.1)/방화벽**으로 제한(nginx 뒤로만). **먼저 8002 외부 노출 여부 실측 필요.**
- **F5**: FastAPI·scheduler를 **jayeondeule(비-root)로 전환** → `restart_service(5)` 무중단 배포 가능, root 권한면적 축소.
