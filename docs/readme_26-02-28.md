## 1. 프로젝트 개요

자연들 스마트팜 AI 어시스턴트는 농업 환경 데이터를 수집·분석하고, AI 기반으로 환경 제어를 자동화하는 통합 시스템입니다.

### 주요 기능

- **AI 대화**: Ollama 로컬 LLM 기반 농업 전문 질의응답 (멀티턴 대화 지원)
- **RAG**: 문서·대화·웹 검색 기반 검색 증강 생성 (ChromaDB 벡터 검색)
- **자동 제어**: 센서 데이터 기반 릴레이 자동 제어 (5분 주기)
- **생육 분석**: 작물 생육 데이터 자동 분석 및 RAG 저장 (12시간 주기)
- **웹 검색**: SearXNG → Naver API → Brave API → MCP 우선순위 체인
- **음성 인터페이스**: STT/TTS 지원
- **실시간 모니터링**: 라즈베리파이 센서 데이터 실시간 수집·표시
- **웹 대시보드**: React + Spring Boot 기반 관리 UI

## 3. 기술 스택

| 계층 | 기술 | 설명 |
|------|------|------|
| **프론트엔드** | React + Vite | SPA, Zustand 상태관리, Bootstrap |
| **백엔드 (AI)** | Python 3.9+ / FastAPI | 비동기 REST API, SSE 스트리밍 |

| **임베딩** | bge-m3 | 다국어 임베딩 모델 |
| **웹 검색** | SearXNG + Naver API + Brave API | 다중 검색 엔진 |
| **스케줄러** | APScheduler | cron/interval 기반 자동화 |
| **인증** | JWT | Spring Security 기반 |
| **API 문서** | Swagger/OpenAPI | springdoc-openapi |
| **하드웨어** | Raspberry Pi + GPIO | 센서 수집, 릴레이 제어 |
| **컨테이너** | Docker | SearXNG 전용 |

## 5. 서비스 관리

### 5.1 통합 관리 스크립트 (`agriAiCore`)

모든 서비스를 하나의 스크립트로 관리합니다.

```bash
# 전체 서비스 관리
sudo ./agriAiCore start       # 전체 시작 (대화형 메뉴)
sudo ./agriAiCore start 0     # 전체 시작 (자동)
sudo ./agriAiCore stop        # 전체 중지
sudo ./agriAiCore restart     # 전체 재시작
sudo ./agriAiCore status      # 전체 상태 확인 (부팅 자동시작 표시)
sudo ./agriAiCore logs        # 서비스별 3줄 상태 요약

# 개별 서비스 제어
sudo ./agriAiCore start 1     # Ollama
sudo ./agriAiCore start 2     # PostgreSQL
sudo ./agriAiCore start 3     # ChromaDB
sudo ./agriAiCore start 4     # Scheduler
sudo ./agriAiCore start 5     # FastAPI
sudo ./agriAiCore start 6     # SearXNG (Docker)
sudo ./agriAiCore start 7     # Spring Boot
sudo ./agriAiCore start 8     # Nginx

# 부팅 시 자동 시작
sudo ./agriAiCore enable      # 자동 시작 활성화
sudo ./agriAiCore disable     # 자동 시작 비활성화
```

### 5.2 서비스 유형별 관리 방식

| 유형 | 서비스 | 시작/중지 | 자동 복구 |
|------|--------|----------|----------|
| **systemd** | Ollama, PostgreSQL, ChromaDB, Spring Boot, Nginx | `systemctl start/stop` | systemd 자동 재시작 |
| **PID 기반** | Scheduler, FastAPI | Python 프로세스 직접 관리 | PID 파일 감시 |
| **Docker** | SearXNG | `docker stop/start` (recreate 아님) | `restart: unless-stopped` 정책 |

### 5.3 systemd 서비스 (`agriAiCore.service`)

```ini
[Unit]
Description=AgriAI Core Services (All Services)
After=network-online.target

[Service]
Type=oneshot

ExecStop=/workspace/jayeondeule/agriAiCore stop 0
EnvironmentFile=/workspace/jayeondeule/.env
TimeoutStartSec=180

[Install]
WantedBy=multi-user.target
```

## 8. AI 파이프라인

### 8.1 질의 처리 흐름

```
사용자 질의
    │
    ▼
[1] 세션 로드 (멀티턴 대화)
    │
    ▼
[2] 의도 분석 (키워드 기반)
    │   ├── 센서 조회 → get_sensor_data 도구
    │   ├── 릴레이 제어 → control_relay 도구
    │   ├── 웹 검색 → web_search 도구
    │   └── 일반 질의 → RAG + LLM
    │
    ▼
[3] RAG 컨텍스트 수집
    │   ├── farm_knowledge (농장 지식)
    │   ├── document_collection (문서)
    │   ├── conversation_collection (대화 기록)
    │   └── web_knowledge (웹 검색 캐시)
    │
    ▼
[4] LLM 생성 (Ollama - Exaone3.5)
    │   ├── 시스템 프롬프트 + RAG 컨텍스트
    │   ├── Function Calling (도구 호출)
    │   └── 스트리밍 응답 (SSE)
    │
    ▼
[5] 응답 반환 + 세션 저장
```

### 8.2 웹 검색 우선순위

```
[1순위] SearXNG (자체 호스팅, 5개 검색엔진 통합)
    │   └── Google, Bing, DuckDuckGo, Brave, Startpage
    ▼ (실패 시)
[2순위] Naver API (한국어 쿼리, 블로그 + 뉴스)
    ▼ (실패 시)
[3순위] Brave Search API
    ▼ (실패 시)
[4순위] MCP web-search (폴백)
```

### 8.3 RAG 구조

#### ChromaDB 컬렉션

| 컬렉션 | 용도 | 데이터 소스 |

|----------|------|

## 11. 설치 및 실행

### 11.1 사전 요구사항

- Ubuntu 22.04+ / Debian 12+
- Python 3.9+
- Java 17+ (Spring Boot)
- Node.js 18+ (React)
- PostgreSQL 12+
- Docker (SearXNG용)
- NVIDIA GPU + CUDA (Ollama 추론)

### 11.2 설치

```bash
# 1. 저장소 클론
git clone <repository-url> /workspace/jayeondeule
cd /workspace/jayeondeule

# 2. Python 가상환경 및 패키지 설치
python3 -m venv venv
source venv/bin/activate
bash setup/requirement.sh

# 3. 환경변수 설정
cp .env.example .env
# .env 파일 편집 (DB, API 키 등)

# 4. systemd 서비스 등록
sudo cp setup/agriAiCore.service /etc/systemd/system/
sudo cp setup/chromadb.service /etc/systemd/system/
sudo systemctl daemon-reload

# 5. SearXNG Docker 설정
docker compose -f setup/searxng/docker-compose.yml up -d

# 6. 프론트엔드 빌드
cd web/frontend
npm install && npm run build

# 7. Spring Boot 빌드
cd web/backend
./mvnw package -DskipTests
```

### 11.3 실행

```bash
# 전체 서비스 시작
sudo ./agriAiCore start

# 부팅 시 자동 시작 등록
sudo ./agriAiCore enable

# 상태 확인
sudo ./agriAiCore status
```

### 11.4 개발 모드

