# AgriAI Core 스케줄 실행 기능 정리

> 작성일: 2026-02-25
> 스케줄러: APScheduler (BackgroundScheduler)
> 설정: coalesce=True, max_instances=1, misfire_grace_time=60

---

## 스케줄 작업 요약

|  실행시간  |    실행주기     |              모듈명               |           함수명            |                실행내용               |
|------------|-----------------|-----------------------------------|-----------------------------|---------------------------------------|
| 매 1분     | Interval(1min)  | schedule_control + manual_control | `_combined_control_job()`   | 조명/관수 스케줄 제어 + 수동 환경제어 |
| 매 3분     | Interval(3min)  | postgres_loader                   | `sync_postgresql_to_vcdb()` | PostgreSQL → ChromaDB 데이터 동기화  |
| 매 10분    | Interval(10min) | stats 모듈                        | `stats_func()`              | 통계 데이터 수집 및 최적조건 분석     |
| 매일 00:00 | Cron(0시0분)    | logs                              | `cleanup_all_logs()`        | 100일 이전 로그 삭제, 파일 트리밍     |
| 매일 04:00 | Cron(4시0분)    | ai 학습 모듈                      | `learning_func()`           | 수집된 데이터로 LLM 학습              |

## 상세 설명

### 1. 릴레이 통합 제어 (매 1분)
- **Job ID**:  `relay_control_job`
- **실행주기**: 매 1분 (Interval)
- **모듈**:    `task_scheduler.py` → `schedule_control.py` + `manual_control.py`
- **함수**:    `_combined_control_job()` (내부에서 2개 함수 순차 호출)

#### 1-1. 스케줄 제어: `control_all_schedules()`
|   항목   |                                                    내용                                                  |
|----------|----------------------------------------------------------------------------------------------------------|
| 모듈     | `agri_ai_core/src/control/schedule_control.py`                                                           |
| 함수     | `control_all_schedules()` → `control_lighting_schedule()` + `control_irrigation_schedule()`             |
| 실행내용 | 모든 활성 재배사를 순회하며, 조명/관수 스케줄 설정(LIGHT_IRRIGATION_S_SETTING)에 따라 릴레이 ON/OFF 제어 |

**실행 유형별 판정 로직**:
|   실행유형 |             판정 방법        |
|------------|------------------------------|
| `daily`    | 매일 동일 시간대에 실행      |
| `interval` | 시작일부터 N일 간격으로 반복 |
| `weekdays` | 특정 요일에만 실행           |

**시간 범위 판정**: `is_time_in_range()` — 자정 넘김(23:00~01:00) 지원

#### 1-2. 수동 환경 제어: `control_all_manual()`
| 항목 | 내용 |
|------|------|
| 모듈 | `agri_ai_core/src/control/manual_control.py` |
| 함수 | `control_all_manual()` → `control_manual_environment()` |
| 실행내용 | 센서 실시간 데이터 기반으로 64케이스 알고리즘에 의한 자동 환경제어 |

**제어 대상 릴레이**: 물가열기, 분사펌프, 열풍기, 흡기팬, 배기팬, 순환댐퍼, 흡기댐퍼, 배기댐퍼, 열풍댐퍼

**제어 흐름**:
```
센서 데이터 읽기 → 비상제어 체크 → 생육단계 분기
  ├─ 비상제어 (최우선): 임계값 이탈 시 즉시 대응
  ├─ 발이기 모드: 29~33℃ 유지 특수 제어
  ├─ 수확기 모드: 관수 강제 OFF
  └─ 일반 제어: 64케이스 알고리즘
       ├─ Phase 1: 댐퍼/펌프/가열기 즉시 제어
       ├─ (15초 대기)
       └─ Phase 2: 팬/열풍기 최종 적용
```

**비상제어 임계값**:
| 조건 | 대응 |
|------|------|
| 온도 < 25℃ | 물가열기+열풍기 ON, 분사펌프 OFF, 내부순환 |
| 온도 > 33℃ | 모든 가열장치 OFF, 배기순환 |
| 습도 < 70% | 물가열기+분사펌프 ON, 내부순환 |
| 습도 > 95% | 모든 가열장치 OFF, 배기순환 |
| CO2 > 1500ppm | 모든 가열장치 OFF, 배기순환 |
| 수온 < 35℃ | 물가열기 ON (다른 장치 유지) |
| 수온 > 60℃ | 물가열기 OFF (다른 장치 유지) |

**열풍기 쿨다운**: 30분 연속 운전 후 5분 쿨다운

### 2. 데이터 내보내기 (매 3분)
- **Job ID**: `data_export_job`
- **실행주기**: 매 3분 (Interval)
- **모듈**: `agri_ai_core/src/ai/rag/postgres_loader.py`
- **함수**: `sync_postgresql_to_vcdb()`

| 항목 | 내용 |
|------|------|
| 데이터 소스 | PostgreSQL (센서/릴레이/생육 테이블) |
| 저장 대상 | ChromaDB `source_collection` |
| 집계 단위 | 3분 단위 시간 정렬 (align_to_3min) |

**처리 흐름**:
```
PostgreSQL 조회
  ├─ read_farm_house_list() → 농장/재배사 목록
  ├─ read_units_data() → 센서 8종 + 릴레이 11종
  └─ read_crops_data() → 생육/수확 데이터
       ↓
데이터 처리 (data_processor.py)
  ├─ process_unit_data()
  │   ├─ 센서값: 3분 구간 평균 (소수점 2자리)
  │   ├─ 릴레이: 3분 구간 다수결 (majority vote)
  │   └─ 텍스트 문서 + 메타데이터 생성
  └─ process_crop_data()
      ├─ 등급별 수익 계산 (수확량 × 판매가격)
      ├─ 총수익, 등급비율 산출
      └─ 텍스트 문서 + 메타데이터 생성
       ↓
ChromaDB upsert (bge-m3 임베딩, 1024차원)
```

**센서 데이터 (8종)**: 내부온도, 내부습도, 외부온도, 외부습도, CO2, 수온, 광량, 수위

**릴레이 데이터 (11종)**: 물가열기, 분사펌프, 배수밸브, 흡기팬, 배기팬, 조명토글, 관수밸브, 열풍기, 순환댐퍼, 흡기댐퍼, 배기댐퍼

**문서 ID 형식**: `{kind}_{farm_id}_{house_id}_{timestamp}`

### 3. 통계 처리 (매 10분)
- **Job ID**: `stats_job`
- **실행주기**: 매 10분 (Interval, STATS_INTERVAL_MINUTES=10)
- **모듈**: stats 처리 모듈
- **함수**: `stats_func()` (외부 주입)

| 항목 | 내용 |
|------|------|
| 실행내용 | stats_collection, optimal_collection에 집계 데이터 저장 |
| 저장 대상 | ChromaDB `stats_collection`, `optimal_collection` |

### 4. 일일 로그 정리 (매일 00:00)
- **Job ID**: `daily_log_cleanup`
- **실행주기**: 매일 00:00 (Cron)
- **모듈**: `agri_ai_core/logs`
- **함수**: `_daily_log_cleanup()` → `cleanup_all_logs()`

| 항목 | 내용 |
|------|------|
| 실행내용 | 100일 이전 로그 파일 삭제, 단일 파일 트리밍, 로그 디렉토리 유지보수 |
| 대상 경로 | `/workspace/jayeondeule/logs/` |

### 5. LLM 학습 (매일 04:00)
- **Job ID**: `learning_job`
- **실행주기**: 매일 04:00 (Cron, SCHEDULE_LEARNING_HOUR=4, SCHEDULE_LEARNING_MINUTE=0)
- **모듈**: AI 학습 모듈
- **함수**: `learning_func()` (외부 주입)

| 항목 | 내용 |
|------|------|
| 실행내용 | 수집된 센서/생육 데이터를 기반으로 LLM 모델 학습 패턴 분석 |
| 관련 컬렉션 | `learned_collection`, `self_learning_collection`, `learning_pattern_collection` |
