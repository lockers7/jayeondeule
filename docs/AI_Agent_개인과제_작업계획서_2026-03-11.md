# AI Agent 개인과제 작업계획서 (2026-03-11)

## 1) 과제 주제
**주제명:** AI 스마트팜 운영 코치 (Multi-Agent RAG Assistant)  
**핵심 역할:** 사용자의 자연어 질문을 이해하고, 농장 문서/운영 데이터 기반으로 근거 있는 답변과 실행 제안을 제공하는 대화형 서비스

차별화 포인트
- 단순 Q&A가 아닌 **운영 의사결정 보조**(예: 환경 제어, 위험 알림, 우선 조치 제안)
- **멀티 에이전트 분업**(의도분석/검색/검증/응답생성)
- **근거 기반 답변(RAG + 출처 표시)**로 신뢰성 강화

## 3) 필요한 기능 (평가요소 매핑)

### 3-1. Prompt Engineering
- 역할 기반 시스템 프롬프트 (도메인 전문가 톤/금지사항/근거 출력 규칙)
- Few-shot 예시 3~5개
- 재사용 가능한 프롬프트 템플릿 분리 (`prompts/`)

### 3-2. LangChain + LangGraph Multi-Agent
- 최소 3개 에이전트 구성
  - `Planner Agent`: 질문 의도/작업 계획 수립
  - `Retriever Agent`: RAG 검색 및 근거 수집
  - `Responder Agent`: 최종 답변 생성 + 출처 표기
- ReAct Tool Agent 포함 (예: 문서검색, 요약, 계산, 정책조회)
- (선택) 대화 메모리(세션 기반 최근 N턴)

### 3-3. RAG
- 데이터 수집/전처리 파이프라인
- 청킹 + 임베딩 + Vector DB 저장
- 질의 시 Top-k 검색 + 재정렬 + 근거 문장 인용
- 출처(문서명/페이지/URL) 표기

### 3-4. 서비스 개발/패키징
- Streamlit 화면
  - 채팅창, 소스 패널, 오류/로딩 상태, 히스토리
- FastAPI (선택이지만 권장)
  - `/chat`, `/chat/stream`, `/rag/index`, `/health`
- Docker (선택)
  - `docker-compose`로 app + vectordb 실행
- 운영 고려
  - `.env` 기반 키 관리, 로깅, 예외 처리, 모듈 분리

## 4) 수행 작업계획 (결과 제출 포함)

### 4-1. 단계별 계획 (7일 기준)
1. **D1: 기획/설계**
   - 문제정의, 사용자 시나리오 3개, 아키텍처 다이어그램 작성
2. **D2: 데이터/RAG 파이프라인**
   - 문서 수집, 전처리, 임베딩, Chroma/FAISS 인덱싱
3. **D3: LangGraph Multi-Agent 구현**
   - 노드/엣지, 상태객체, Tool 연결, 실패 fallback
4. **D4: FastAPI 백엔드**
   - 채팅 API, 스트리밍 API, 인덱싱 API
5. **D5: Streamlit UI**
   - 대화형 화면, 소스표시, 세션관리
6. **D6: 품질 강화**
   - 프롬프트 튜닝, 에러처리, 로깅, 응답시간 개선
7. **D7: 패키징/제출물**
   - Docker(선택), 실행가이드, 데모 시나리오, 결과 리포트

### 4-2. 산출물(제출 체크리스트)
- 소스코드 (`app/`, `agents/`, `rag/`, `ui/`, `api/`)
- 실행 문서 (`README.md`, `.env.example`)
- 아키텍처 다이어그램 1장
- 데모 시나리오 3건(입력/출력/근거)
- 성능 및 품질 결과표(정확도/응답시간/실패케이스)

### 4-3. 완료 기준(Definition of Done)
- Streamlit에서 실제 질의응답 가능
- LangGraph 기반 멀티에이전트 플로우 동작 로그 확인
- RAG 검색 근거를 답변과 함께 표시
- 최소 3개 실사용 시나리오 재현 가능
- 환경변수 기반 보안 처리(API Key 하드코딩 금지)

## 5) 결과 보고 (이번 요청 기준)

### 5-1. 분석 결과
- 과제 필수요소 관점에서 필요한 환경/기능/프로토콜을 도출함

- Streamlit 화면에서 대화, 근거 확인, 히스토리 관리까지 일관된 사용자 경험 제공
