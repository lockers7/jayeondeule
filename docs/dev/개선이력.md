# 통합 개선 방안 계획서 (현재 소스 기준)

작성일: 2026-03-01  
대상: `agri_ai_core`, `web/backend`, `setup/nginx`, `raspi`

## 1) 목적
- 현재 소스 기준의 버그/성능/정합성 이슈를 단계적으로 해소한다.
- 기능 변경보다 안정화와 회귀 방지를 우선한다.
- 모든 개선은 테스트 가능한 완료 기준을 포함한다.

## 2) 실행 우선순위 (Top 6)
1. `str.replace` 오치환 제거 (LLM 후처리)
2. 대화 요약 VectorDB 저장 시그니처 수정
3. 임베딩 차원 불일치 제거
4. `DatabaseHandler` 싱글톤 레이스 방지
5. 필터 중복 호출 통합
6. RBAC (`HOUS_MANAGER` + authorities) 정합화
