① 편집 방식 제약

"블록 통째 재작성(Write) 대신 최소 편집(Edit) 으로 변경분만 추가하라. 기존 함수·출력필드·분기·에러메시지·로그를 제거하지 마라. 제거가 불가피하면 먼저 사유를 보고하고 승인을 받아라."

② 삭제줄 검증 의무 (가장 강력)

"변경 후 반드시 git diff 의 삭제(-)된 줄을 전부 나열하고, 각 줄이 왜 안전한지(동일치환/상위집합/승인된 제거)를 설명하라. 설명 못 하는 삭제는 즉시 원복하라."

③ 회귀 고정

"변경 전 기존 동작을 고정하는 테스트를 먼저 만들고, 변경 후에도 통과함을 보여라."
