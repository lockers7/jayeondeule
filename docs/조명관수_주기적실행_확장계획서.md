# 조명/관수밸브 주기적 실행 기능 확장 계획서

## 1. 개요

### 1.1 목적
현재 매일 실행되는 조명/관수밸브 스케줄을 **N일마다 실행**하는 주기적 스케줄 기능으로 확장

### 1.2 현재 상태
- 테이블: `light_irrigation_s_setting`
- 현재 기능: 매일 `strt_time ~ fnsh_time` 시간대에 조명/관수밸브 실행
- 제약사항: 주기(며칠마다) 설정 불가능

### 1.3 목표
- **주기 설정 기능 추가**: 1일, 2일, 3일, 7일(주1회) 등 유연한 주기 설정
- **시작일 기준**: 특정 날짜부터 주기 계산
- **요일 선택 기능**: 월/수/금 같은 특정 요일만 선택 가능
- 기존 매일 실행 스케줄과 호환성 유지

### 2.2 확장 테이블 구조 (안 A: 컬럼 추가) ✅ **적용완료**

**장점**: 기존 데이터 유지, 간단한 마이그레이션
**단점**: NULL 허용 컬럼 증가

```sql
ALTER TABLE light_irrigation_s_setting
ADD COLUMN excs_type VARCHAR(20) DEFAULT 'daily',  -- 'daily', 'interval', 'weekdays'
ADD COLUMN excs_itvl INT DEFAULT NULL,             -- 며칠마다 (2, 3, 7 등)
ADD COLUMN excs_strt_date DATE DEFAULT NULL,       -- 주기 시작일

-- 기본값 설정으로 기존 데이터 호환
UPDATE light_irrigation_s_setting
SET excs_type = 'daily'
WHERE excs_type IS NULL;

-- 컬럼 주석
COMMENT ON COLUMN light_irrigation_s_setting.excs_type IS '실행 유형: daily(매일), interval(N일마다), weekdays(요일선택)';
COMMENT ON COLUMN light_irrigation_s_setting.excs_itvl IS 'N일마다 실행 (excs_type=interval일 때 사용)';
COMMENT ON COLUMN light_irrigation_s_setting.excs_strt_date IS '주기 시작일 (excs_type=interval일 때 사용)';
COMMENT ON COLUMN light_irrigation_s_setting.excs_wkdy IS '실행 요일 (excs_type=weekdays일 때 사용, 예: 1,3,5는 월/수/금)';
```

**컬럼명 매핑:**
| 계획서 원안 | 실제 적용 | 설명 |
|------------|----------|------|
| exec_type | excs_type | 실행 유형 |
| exec_interval | excs_itvl | 실행 간격 (일) |
| exec_start_date | excs_strt_date | 시작일 |
| exec_weekdays | excs_wkdy | 실행 요일 |

**excs_type 값:**
- `daily`: 매일 실행 (기본값, 기존 동작)
- `interval`: N일마다 실행 (excs_itvl, excs_strt_date 사용)
- `weekdays`: 특정 요일만 실행 (excs_wkdy 사용)

**excs_wkdy 형식:**
- `1,2,3,4,5,6,7` (1=월요일, 7=일요일)
- 예시: `1,3,5` = 월/수/금만 실행

### 3.2 스케줄 제어 로직 수정

**파일**: [agri_ai_core/control/relay/schedule_control.py](agri_ai_core/control/relay/schedule_control.py)

**추가 함수 1: 주기 기반 실행 여부 확인**

```python
from datetime import datetime, date

def should_execute_interval(start_date, interval, current_date):
    """
    주기 기반 스케줄 실행 여부 확인

    Args:
        start_date: 시작일 (date 객체)
        interval: 주기 (일 단위, int)
        current_date: 현재 날짜 (date 객체)

    Returns:
        bool: 실행 여부
    """
    if not start_date or not interval:
        return False

    # 시작일로부터 경과 일수
    days_elapsed = (current_date - start_date).days

    # 주기로 나누어 떨어지면 실행
    return days_elapsed % interval == 0
```

**추가 함수 2: 요일 기반 실행 여부 확인**

```python
def should_execute_weekdays(weekdays_str, current_date):
    """
    요일 기반 스케줄 실행 여부 확인

    Args:
        weekdays_str: 요일 문자열 ('1,3,5' 형식)
        current_date: 현재 날짜 (date 객체)

    Returns:
        bool: 실행 여부
    """
    if not weekdays_str:
        return False

    # 현재 요일 (1=월요일, 7=일요일)
    current_weekday = current_date.isoweekday()

    # 설정된 요일 목록
    allowed_weekdays = [int(w.strip()) for w in weekdays_str.split(',')]

    return current_weekday in allowed_weekdays
```

**수정 함수: control_lighting_schedule**

```python
def control_lighting_schedule(farm_id, house_id):
    """
    조명 스케줄에 따라 조명 제어 (주기 기능 추가)
    """
    try:
        # 조명 설정 조회 (dlte_yn = False만)
        light_settings = read_light_irrigation_settings(farm_id, house_id, 'light')

        if not light_settings:
            logger.debug(f"농장 {farm_id}, 재배사 {house_id}: 조명 스케줄 없음")
            return {
                "success": True,
                "action": "none",
                "message": "조명 스케줄이 설정되지 않음"
            }

        # 현재 시간
        now = datetime.now()
        current_time = now.time()
        current_date = now.date()

        # 조명을 켜야 하는 시간대인지 확인
        should_turn_on = False
        active_schedules = []

        for setting in light_settings:
            start_time = setting.get('strt_time')
            finish_time = setting.get('fnsh_time')
            exec_type = setting.get('exec_type', 'daily')
            exec_interval = setting.get('exec_interval')
            exec_start_date = setting.get('exec_start_date')
            exec_weekdays = setting.get('exec_weekdays')

            # 시간대 확인
            if not (start_time and finish_time):
                continue

            if not is_time_in_range(current_time, start_time, finish_time):
                continue

            # 실행 유형에 따른 추가 확인
            should_execute = False

            if exec_type == 'daily':
                # 매일 실행
                should_execute = True

            elif exec_type == 'interval':
                # N일마다 실행
                should_execute = should_execute_interval(
                    exec_start_date, exec_interval, current_date
                )

            elif exec_type == 'weekdays':
                # 특정 요일만 실행
                should_execute = should_execute_weekdays(
                    exec_weekdays, current_date
                )

            if should_execute:
                should_turn_on = True
                schedule_info = f"{start_time.strftime('%H:%M')}-{finish_time.strftime('%H:%M')}"

                # 주기 정보 추가
                if exec_type == 'interval':
                    schedule_info += f"({exec_interval}일마다)"
                elif exec_type == 'weekdays':
                    weekday_names = {1: '월', 2: '화', 3: '수', 4: '목', 5: '금', 6: '토', 7: '일'}
                    days = [weekday_names.get(int(d.strip()), d) for d in exec_weekdays.split(',')]
                    schedule_info += f"({'/'.join(days)})"

                active_schedules.append(schedule_info)

        # 릴레이 설정
        relay_settings = {
            "lighting_flag": should_turn_on
        }

        # 릴레이 값 설정
        result = set_relay_value(farm_id, house_id, relay_settings)

        if result.get("success"):
            status = "ON" if should_turn_on else "OFF"
            schedule_info = f" (스케줄: {', '.join(active_schedules)})" if active_schedules else ""
            logger.info(f"농장 {farm_id}, 재배사 {house_id}: 조명 {status}{schedule_info}")

            return {
                "success": True,
                "action": "lighting_controlled",
                "status": status,
                "schedules": active_schedules,
                "message": f"조명 {status}"
            }
        else:
            logger.error(f"농장 {farm_id}, 재배사 {house_id}: 조명 제어 실패 - {result.get('message')}")
            return {
                "success": False,
                "message": f"조명 제어 실패: {result.get('message')}"
            }

    except Exception as e:
        logger.error(f"조명 스케줄 제어 중 오류: {e}")
        logger.error(traceback.format_exc())
        return {
            "success": False,
            "message": f"오류 발생: {str(e)}"
        }
```

## 7. 주의사항 및 위험 요소

### 7.1 주의사항

1. **기존 데이터 호환성**
   - 마이그레이션 시 기존 스케줄은 모두 `exec_type='daily'`로 자동 설정
   - 기존 동작 변경 없음 보장

2. **시작일 설정**
   - `exec_type='interval'`일 때 `exec_start_date`는 필수
   - NULL이면 주기 계산 불가 → 실행 안 됨

3. **요일 형식 검증**
   - `exec_weekdays`는 '1,2,3,4,5,6,7' 형식만 허용
   - 잘못된 형식 입력 시 로그 경고 + 해당 스케줄 스킵

### 7.2 위험 요소

| 위험 | 영향도 | 대응 방안 |
|------|--------|----------|
| 마이그레이션 실패 | 높음 | 롤백 스크립트 준비, 백업 필수 |
| 주기 계산 오류 | 중간 | 단위 테스트 철저히, edge case 검증 |
| 성능 저하 (날짜 계산) | 낮음 | 인덱스 최적화, 쿼리 성능 모니터링 |
| 사용자 혼란 (UI 없음) | 중간 | 관리자 가이드 문서 작성 |
