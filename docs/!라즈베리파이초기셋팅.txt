[IP 규칙]
- IP 주소: 192.168.0.1XX (XX = house_id + 100)
  예) house_id=1 → 192.168.0.101, house_id=3 → 192.168.0.103
- house_id는 IP 마지막 자리에서 100을 뺀 값으로 자동 계산됨 (config.py)

1단계: 네트워크 설정 (고정 IP)
================================================================================

# WiFi 연결명 확인
nmcli con show

# 고정 IP 설정 (XXX 부분을 해당 장비의 IP로 변경)
# 연결명은 nmcli con show에서 확인한 이름 사용 (예: preconfigured, netplan-wlan0-LimsFarm_5G 등)
sudo nmcli con mod "연결명" ipv4.addresses 192.168.0.XXX/24 ipv4.gateway 192.168.0.254 ipv4.dns 192.168.0.254 ipv4.method manual
sudo nmcli con up "연결명"

================================================================================
4단계: 하드웨어 인터페이스 활성화 (raspi-config)
================================================================================

# I2C 활성화 (SHT45, BME280 센서용)
sudo raspi-config nonint do_i2c 0

# 1-Wire 활성화 (DS18B20 수온센서용)
sudo raspi-config nonint do_onewire 0

# SPI 비활성화
sudo raspi-config nonint do_spi 1

================================================================================
5단계: /boot/firmware/config.txt 수정
================================================================================

sudo nano /boot/firmware/config.txt

# [all] 섹션에 아래 내용 추가 (기존 [all] 내용 교체)
[all]
dtoverlay=w1-gpio
dtoverlay=pi3-miniuart-bt
dtparam=uart0=on
enable_uart=1

dtparam=i2c_arm=on

14단계: systemd 서비스 등록
================================================================================

# 서비스 파일 생성
sudo tee /etc/systemd/system/jayeondeule_ctrl.service << 'EOF'
[Unit]
Description=Jayeondeule Smart Farm Control Service
After=network.target

[Service]
ExecStart=/home/jayeondeule/jayeondeule/bin/python3 /home/jayeondeule/FarmUnits/jayeondeule.py
WorkingDirectory=/home/jayeondeule/FarmUnits/
StandardOutput=inherit
StandardError=inherit
Restart=always
User=root
Group=root

[Install]
WantedBy=multi-user.target
EOF

# 서비스 등록 및 시작
sudo systemctl daemon-reload
sudo systemctl enable jayeondeule_ctrl.service
sudo systemctl start jayeondeule_ctrl.service

# CO2 센서 시리얼 테스트
source ~/jayeondeule/bin/activate
sudo ~/jayeondeule/bin/python3 -c "
import serial, time
ser = serial.Serial('/dev/ttyAMA0', 9600, timeout=2)
ser.write(bytes([0xFF,0x01,0x86,0x00,0x00,0x00,0x00,0x00,0x79]))
time.sleep(1)
resp = ser.read(9)
if len(resp)==9: print(f'CO2: {resp[2]*256+resp[3]} ppm')
else: print(f'응답 없음 (len={len(resp)}) - 시리얼 콘솔 비활성화 확인')
ser.close()
"

================================================================================
하드웨어 연결 정보 (GPIO 핀 매핑)
================================================================================

[센서]
- SHT45 (실내 온습도)  : I2C (SCL/SDA, 주소 0x44)
- BME280 (실외 온습도)  : I2C (SCL/SDA, 주소 0x76)
- MH-Z19B (CO2)        : UART (/dev/ttyAMA0, 9600bps)
- DS18B20 (수온)       : 1-Wire (GPIO 4, 풀업저항 4.7kΩ 필요)
- 조도 센서             : GPIO 17
- 수위 센서             : GPIO 27

[릴레이 16채널 GPIO 매핑]
GPIO 22 → 릴레이 01: 물가열기 (CHILLER)
GPIO 23 → 릴레이 02: 분사펌프 (CYCLE_MOTOR)
GPIO  9 → 릴레이 03: 배수펌프 (RELEASE_WATER_1)
GPIO 25 → 릴레이 04: 미사용   (RELEASE_WATER_2)
GPIO 11 → 릴레이 05: 흡기팬   (IN_FAN_MOTOR)
GPIO  8 → 릴레이 06: 배기팬   (OUT_FAN_MOTOR)
GPIO  5 → 릴레이 07: 조명토글 (LIGHT)
GPIO  7 → 릴레이 08: 관수토글 (WATER)
GPIO  6 → 릴레이 09: 열풍기   (HEATER)
GPIO 12 → 릴레이 10: 순환댐퍼 (CYCLE_VALVE)
GPIO 13 → 릴레이 11: 흡기댐퍼 (IN_VALVE)
GPIO 16 → 릴레이 12: 미사용
GPIO 19 → 릴레이 13: 미사용
GPIO 20 → 릴레이 14: 배기댐퍼 (OUT_VALVE)
GPIO 26 → 릴레이 15: 열풍댐퍼 (HEATER_VALVE)
GPIO 21 → 릴레이 16: 미사용

트러블슈팅

[서비스 시작 실패]
sudo journalctl -u jayeondeule_ctrl.service --no-pager -n 30

[시리얼 포트 없음 (/dev/ttyAMA0)]
- config.txt [all] 섹션에 dtoverlay=pi3-miniuart-bt, dtparam=uart0=on 확인
- cmdline.txt에서 console=serial0,115200 삭제 확인
- 재부팅 후 ls -la /dev/serial0 확인

[I2C 센서 미감지]
- sudo raspi-config nonint get_i2c 결과가 0인지 확인 (0=활성)
- config.txt에 dtparam=i2c_arm=on 확인
- /etc/modules에 i2c-dev 확인
- 배선 확인 (SDA=GPIO2, SCL=GPIO3)

[DS18B20 수온 127.937]
- 풀업저항 4.7kΩ 확인 (데이터핀-VCC 사이)
- 배선 접촉 확인
- ls /sys/bus/w1/devices/ 에서 28-XXXX 디바이스 존재 확인

[DB 연결 오류]
- ~/FarmUnits/.env 파일의 HOST, PORT, DATABASE, USER, PASSWORD 확인
- 서버(lockers7.iptime.org:5432) 접근 가능 여부 확인

[서비스 재시작]
sudo systemctl restart jayeondeule_ctrl.service
